⭐ Flagship — RAG Chatbot
<details open> <summary><b>🧠 RAG Chatbot — Chat With Your Documents</b></summary> <br/>

A Retrieval-Augmented Generation chatbot that lets users upload documents (PDF, DOCX, TXT) and ask questions in natural language. Instead of relying only on the LLM's memory, it retrieves the most relevant passages from the user's own knowledge base and generates grounded answers with source references — reducing hallucinations and keeping responses tied to real content.

Aspect	Details
Stack	Python, LangChain, FastAPI, React.js, Ollama / OpenAI API
Retrieval	Document chunking → embeddings → FAISS / ChromaDB vector store → top-K semantic search
Generation	Context-grounded prompting with source citations to reduce hallucination
Features	Multi-document upload, conversational memory, streaming responses, source attribution
Privacy	Runs fully local with Ollama — documents never have to leave the machine
Architecture	Decoupled ingestion pipeline, retrieval service, and chat UI behind a REST API
Deployment	Dockerized backend, frontend on Vercel / Netlify
Repository	rag-chatbot

Why it matters: this project covers the full GenAI application lifecycle — ingestion, embeddings, vector search, prompt design, LLM serving, API design, and a polished chat interface — the exact skills needed to ship LLM products in the real world.

Roadmap: hybrid search (BM25 + vectors) · re-ranking · RAG evaluation (faithfulness & relevance) · multi-user auth · agentic tool use
